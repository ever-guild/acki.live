Contributing

This agreement is for collaboration. If instructions are unclear, ask your colleagues. We value clarity and speed.

1

Get the Code

Clone the repository to start developing.

git clone git@github.com:ever-guild/dev.acki.live.git
cd dev.acki.live
git checkout -b name-of-feature origin/develop
Or Existing
cd dev.acki.live
git fetch --prune
git checkout -b dev/name-of-feature origin/develop
2

Write Code

Follow Development guidelines for local testing. Use Conventional Commits.

Featuregit commit --message "feat: paypal payment for different users"
Fixgit commit --message "fix: hide password display when searching"
3

Make Pull Requests 

git push --set-upstream origin dev/name-of-feature

Follow the link generated in the terminal to create the PR:
https://github.com/ever-guild/dev.acki.live/pull/new/dev/name-of-feature

4

Sync & Update

Keep History Linear

Fetch latest upstream changes and rebase to maintain a clean history. Resolve conflicts if they appear.

git fetch --prune origin
git rebase --autostash --ignore-date origin/develop
Pro Tip: Use an alias for efficiencygit dup

Force Push Required

Since history is rewritten, use force push to update:

git push --force --set-upstream origin dev/name-of-feature

Keep in Sync

There is no mailing list on this route. Track changes through the repository itself: watch discussions, review open pull requests, and keep local work aligned with the repo rules before you push.
